Test your own network.

A rate network, a transformer run step by step, a spiking simulation, neuromorphic hardware, a brain emulation: the test records it at rest and while briefly pushing single units, measures eight signatures of its activity, and checks each against recordings of 113 real C. elegans nervous systems probed the same way.

Run the test ↓

What it measures.

Each signature is a property of activity anyone can check: how few patterns the resting activity uses, how slow it is, how much units move together, its timescale, how far a push to one unit spreads, how much the pushed unit stands out, whether a second push gets a weaker answer, and how well the system can be copied by watching it. For each, the reference is the range that groups of real worms span. A system's distance is how far it sits outside those ranges, on average.

The reference board.

The systems the test was calibrated on, ranked by distance from real worms. Groups of real worms held out of the reference sit at 0.29 to 0.60; that is the mark to beat.

Run it.

The test needs its server, which this copy of the site does not run. When the site is served with it, this page is the live test: upload recordings, weights (.npz or ONNX) or a Python class, and get a result page and a place on the board. To run it on your own machine:

# the site and the live test, at http://localhost:8642 git clone https://github.com/Weptune/nematica cd nematica python3 -m pip install -r deploy/brainlike/requirements.txt web/serve.sh # or test one system from the command line python -m nematica brainlike my_rnn.npz python -m nematica brainlike model.onnx python -m nematica brainlike my_system.py --class System

Reference data: Randi et al. 2023, the signal propagation atlas of C. elegans (CC BY 4.0), summary numbers only. The protocol, its calibration and every amendment are in the repository.
