# Kunert et al. 2014 connectome model data

`Gg.npy` (gap-junction counts), `Gs.npy` (chemical synapse counts), `emask.npy` (1 = inhibitory
reversal potential) and `neuron_names.txt` for 279 neurons, from the C. elegans Neural Interactome
(Kim, Leahy, Shlizerman 2019; https://github.com/shlizee/C-elegans-Neural-Interactome),
BSD 3-Clause licence (see LICENSE). Model: Kunert, Shlizerman, Kutz 2014, "Low-dimensional
functionality of complex network dynamics: neurosensory integration in the Caenorhabditis
elegans connectome", Phys Rev E. Re-saved with numpy for Python 3; values unchanged.
