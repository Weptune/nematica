HOW THE TEST WORKS

A ruler for brains, measured in real worms.

No two real worm brains behave alike, so "close to a real brain" needs a unit. Ours is how different real worms are from each other. For every test, we measure how far an artificial brain is from each real worm, and how far real worms are from one another.

TOO TYPICAL
closer to every worm than worms are to each other: an average worm, which no real worm is
INSIDE · PASS
as different from real worms as they are from each other
OUTSIDE
further from real worms than they are from each other

The verdict comes from a bootstrap over worms: resampling which real worms are in the comparison, the artificial brain must sit within the spread of real worm-to-worm distances.

TESTING THE TEST

Before scoring any model, we break real brains on purpose.

Each family of tests is checked with altered real recordings whose correct verdict is written down in advance: shuffling time must fail the timing tests, scrambling which neuron was stimulated must fail the echo pattern, tripling every response must fail echo size. A test that does not catch what it is designed to catch is reported, not hidden.
